# Formula Level Requests
A better way to take level requests, powered by the team behind [req.gd](https://req.gd)

## Information
This is the official mod of the Formula request system, a project aimed to making level requests as streamlined as possible.

To set it up:
1. Create an account on the website.
2. Create a full access API key in your account settings.
3. Paste the API key into the mod settings.
4. Open the Formula menu after going to the search menu. 

To actually get requests, you'll have to open your queue in the req.gd settings and share your link. You can change your username and the link will update as well.

If you want someone else to view your queue, make them a view-only API key in your account for them to paste into the mod settings. You are also able to limit how many requests you get per user in the site settings.
